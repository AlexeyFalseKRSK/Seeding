## Описание

**Seeding** разрабатывается в рамках курсовой работы и ВКР как учебный и исследовательский инструмент. Приложение работает локально на одном ПК без серверной части: пользователь загружает изображения или PDF-документы, запускает детекцию и классификацию сеянцев, просматривает результаты в интерфейсе и экспортирует итоговый PDF-отчёт.

Архитектура намеренно остаётся простой:

- одна учётная запись активна за раз;
- данные хранятся локально в SQLite;
- роли, ACL и серверная инфраструктура не предусмотрены.

Подробное описание архитектуры — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Возможности

- Входные форматы: `png`, `jpg`, `jpeg`, `bmp`, `tiff`, `pdf`
- Детекция сеянцев на текущем изображении или на всех страницах PDF
- Классификация частей найденных объектов (корень, стебель, соцветие и др.)
- Отображение результатов в дереве слоёв и панели статистики
- Интерактивное редактирование ограничивающих рамок и масок на холсте
- Поворот изображений и кропов с пересчётом координат и масок
- Калибровка масштаба (пикселей/мм) с визуальным инструментом измерения
- Формирование PDF-отчёта с аннотированными изображениями и таблицами
- Локальное хранение пользователей с PBKDF2-HMAC-SHA256 и аудит-логирование действий в SQLite
- Управление учётными записями через CLI (`seeding-users`)

## Быстрый старт

### Требования

- Python 3.10 или новее
- Файлы весов моделей `.pt` (см. [Конфигурация](#конфигурация))

### Установка

```bash
# 1. Клонировать репозиторий
git clone https://github.com/AlexeyFalseKRSK/Seeding.git
cd Seeding

# 2. Создать виртуальное окружение
# Windows
python -m venv .venv
.venv\Scripts\activate

# Linux / macOS
python3 -m venv .venv
source .venv/bin/activate

# 3. Установить зависимости
pip install -e .
```

### Первый запуск

```bash
# Создать первого пользователя
python -m seeding.manage_users create admin

# Запустить приложение
python -m seeding.main
# или через entrypoint после pip install -e .
seeding
```

## Конфигурация

### Пути к моделям

Приложение ищет веса в следующем порядке:

1. Аргументы командной строки (`--weights`, `--classify-weights`)
2. Переменные окружения
3. Значения по умолчанию из `seeding/config.py`

| Параметр | Аргумент CLI | Переменная окружения | Значение по умолчанию |
|---|---|---|---|
| Модель детекции | `--weights` | `YOLO_WEIGHTS_PATH` | `models/bestDetectNew.pt` |
| Модель классификации | `--classify-weights` | `YOLO_CLASSIFY_WEIGHTS_PATH` | `models/bestKlassSegFlip180.pt` |
| Путь к базе данных | — | `SEEDING_DB_PATH` | `seeding/data/seeding.sqlite3` |

### Примеры запуска

```bash
# Базовый запуск (используются пути из config.py)
seeding

# С явным указанием моделей
seeding --weights models/bestDetectNew.pt --classify-weights models/bestKlassSegFlip180.pt

# Через переменные окружения
YOLO_WEIGHTS_PATH=models/bestDetectNew.pt seeding

# С внешней базой данных
SEEDING_DB_PATH=/data/mydb.sqlite3 seeding
```

### Пороговые значения (seeding/config.py)

| Параметр | Значение |
|---|---|
| Порог уверенности детекции | 0.25 |
| IoU для NMS | 0.40 |
| Высокая уверенность (зелёный цвет) | ≥ 0.90 |
| Низкая уверенность (красный цвет) | < 0.50 |

## Использование

### Рабочий процесс

1. Создать пользователя через CLI и запустить приложение
2. Пройти авторизацию в диалоге входа
3. Открыть изображение или PDF-документ (`Ctrl+O`)
4. Запустить детекцию сеянцев на текущей странице (`Ctrl+F`) или на всём документе (`Ctrl+Shift+F`)
5. Выбрать найденный объект в дереве слоёв или на холсте
6. Запустить классификацию частей выбранного объекта (`Ctrl+C`)
7. При необходимости отредактировать ограничивающую рамку или повернуть изображение (`Ctrl+R`)
8. Проверить статистику в правой панели
9. Сформировать PDF-отчёт (`Ctrl+P`)

### Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl + O` | Открыть файл |
| `Ctrl + Shift + O` | Добавить файлы к проекту |
| `Ctrl + F` | Детекция на текущей странице |
| `Ctrl + Shift + F` | Детекция на всех страницах |
| `Ctrl + C` | Классификация частей выбранного объекта |
| `Ctrl + R` | Повернуть текущую страницу или объект на 90° |
| `Ctrl + P` | Сформировать PDF-отчёт |
| `Ctrl + +` | Увеличить масштаб |
| `Ctrl + -` | Уменьшить масштаб |
| `Ctrl + 0` | Сбросить масштаб |
| `Колесо мыши` | Масштабирование холста |
| `ПКМ + перетаскивание` | Панорамирование холста |

## Управление пользователями

База данных пользователей — `seeding/data/seeding.sqlite3`. Схема — `seeding/data/schema.sql`.

Пароли хранятся исключительно в виде хэша PBKDF2-HMAC-SHA256 (120 000 итераций, случайная соль). Логи действий пишутся в таблицу `user_logs`.

### CLI-команды

```bash
# Создать пользователя (пароль запрашивается интерактивно)
python -m seeding.manage_users create alice
seeding-users create alice

# Список пользователей
python -m seeding.manage_users list
seeding-users list

# Сменить пароль
python -m seeding.manage_users set-password alice
seeding-users set-password alice

# Удалить пользователя (потребует подтверждения)
python -m seeding.manage_users delete alice
# Удалить без подтверждения
python -m seeding.manage_users delete alice --yes
```

### Формат логина

- Длина: от 3 до 50 символов
- Допустимые символы: латинские буквы, цифры, `.`, `-`, `_`
- Регистронезависим (хранится в нижнем регистре)

### Действия, попадающие в лог

| Действие | Описание |
|---|---|
| `login` | Успешный вход |
| `logout` | Выход из системы |
| `detect_page` | Детекция на странице |
| `detect_all` | Детекция на всём документе |
| `classify` | Классификация объекта |
| `generate_report` | Создание PDF-отчёта |
| `rotate` | Поворот изображения или объекта |

## Ограничения

- Для работы необходимы файлы весов моделей `.pt`; полный комплект может отсутствовать в минимальной поставке
- Инференс YOLO выполняется в основном потоке — при обработке крупных PDF интерфейс временно не отвечает
- Функция undo/redo для трансформаций изображений не реализована
- Сетевой и многопользовательский режим не предусмотрен
- Поддержка только формата весов `.pt` (Ultralytics/PyTorch); ONNX не поддерживается
