## Блок 1 — Мультиконтурные маски

### Проблема
`bitmap_to_polygon` извлекает только один наибольший контур. При отрисовке пустоты внутри сложных структур (корни, хвоя) заливаются цветом — оператор видит сплошное пятно вместо реальной морфологии.

### Решение
Добавить в `mask_refiner.py` функцию `bitmap_to_contours`:

```python
def bitmap_to_contours(binary_mask: np.ndarray) -> list[np.ndarray]:
    """Возвращает все контуры (внешние + дыры) через RETR_CCOMP."""
```

- Использует `cv2.findContours` с `RETR_CCOMP` — возвращает иерархию контуров (внешние + дыры)
- Возвращает `list[np.ndarray]`, каждый элемент — контур Nx2 float32

В `main_window.py` при отрисовке маски:
- Строить `QPainterPath` с `setFillRule(Qt.OddEvenFill)`
- Для каждого контура из `bitmap_to_contours` — `path.addPolygon(QPolygonF(...))`
- Результат: пустоты между структурами автоматически не закрашиваются

### Что не меняется
- `mask_polygon` в `AllClassImage` — остаётся один контур для совместимости/экспорта
- `mask_bitmap` — основной источник данных, не меняется
- Логика инференса и `mask_refiner.refine_mask_bitmap`

## Блок 2 — Добавление боксов вручную

### Модель данных
`ObjectImage` и `AllClassImage` получают новое поле:
```python
manual: bool = False
```

### UX-процесс
1. В тулбаре — кнопка-переключатель **"✏️ Добавить бокс"** (toggle)
2. В активном режиме курсор меняется на перекрестие
3. Оператор рисует прямоугольник мышью (левая кнопка + drag)
4. После отпускания — диалог выбора класса:
   - 🌱 Сеянец (`seeding`)
   - 🫚 Корень (`root`)
   - 🌿 Стебель (`stem`)
   - 🌸 Соцветие (`inflorescence`)
5. После нажатия "Добавить":
   - Crop bbox вырезается из изображения страницы
   - `mask_refiner.refine_mask_bitmap` строит `mask_bitmap` по яркости
   - `bitmap_to_polygon` строит `mask_polygon` для совместимости
   - Создаётся объект с `confidence=1.0`, `manual=True`
   - Бокс добавляется на сцену (`BBoxItem`) с теми же визуальными свойствами что и автоматические
   - Объект добавляется в дерево навигации
6. **Escape** во время рисования — отмена

### Тип добавляемого объекта
- Если выбран класс **"Сеянец"** — создаётся `ObjectImage`, добавляется в `class_object_image[page_index]`
- Если выбран **корень/стебель/соцветие** — создаётся `AllClassImage`, добавляется в `image_all_class` активного сеянца (если сеянец выбран в дереве) либо предлагается выбрать родительский сеянец

## Блок 3 — Улучшенная навигация

### Изменения в `LayerTreeWidget`
- Иконки по классу: 🌱 сеянец, 🫚 корень, 🌿 стебель, 🌸 соцветие, ✏️ ручной объект
- Подсветка строк с `confidence < 0.5`: оранжевый фон + префикс ⚠️
- Страницы отображают счётчик сеянцев

### Горячие клавиши
- `→` — следующий сеянец на текущей странице
- `←` — предыдущий сеянец на текущей странице
- `↑` / `↓` — уже работает (стандартное дерево)

### Детальная панель (правая панель)
Расширение существующей правой панели — при выборе элемента в дереве показывает:
- Название и класс объекта
- `confidence` (или "ручной" если `manual=True`)
- Crop изображения с наложенной маской (120×100 px превью)
- Размер bbox в px и мм (если откалибровано)
- Кнопки **"◀ Пред"** / **"След ▶"** (дублируют `←` / `→`)

### Что не меняется
- Трёхуровневая структура дерева: страница → сеянец → часть
- Логика выбора и сигналы `itemClicked`
- Расположение панелей в `QSplitter`
